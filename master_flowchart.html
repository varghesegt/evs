The 7 Critical Automated Decision Diamonds (Proper Decision Making & Branching)

Unlike simple linear pipelines, EcoShare AI employs strict algorithmic decision gates to guarantee food safety, payload efficiency, and cryptographic accountability:

DECISION D1 • AUTHENTICATION
Donor Profile & JWT Session Authenticated?
YES [Authenticated]: Proceed to Volumetric Computer Vision surface extraction.
NO [Unauthenticated]: Redirect to Spring Security registration; issue 24h HMAC-SHA512 token and loop back into intake pipeline.

DECISION D2 • VOLUMETRICS
Standard Calibrated Receptacle Identified?
YES [Calibrated]: Reference 5L/10L/20L/50L matrix. Apply +5% repeatability boost (89% confidence, ±8% error margin).
NO [Custom Receptacle]: Heuristic volume calculation using fill %; baseline 82% confidence, ±12% statistical uncertainty.

DECISION D3 • BIO-SAFETY GATE
Microbiological Safety: Is Food Safe (t_rem > 0)?
YES [Fresh]: Batch approved for human consumption pipeline; trigger priority urgency calculator.
NO [Expired / Biohazard]: Circuit breaker trips! Lock status to BIO_DIVERTED; automatically divert to municipal composting / biogas (GWP 28× Methane credit).
t_rem = T_shelf - Δt_elapsed > 0
DECISION D4 • PRIORITY LEVEL
Urgency Critical? (P ≥ 75 OR t_rem ≤ 2h)
YES [Critical]: Emergency Dispatch Protocol: push real-time alert to nearby high-capacity shelters with 10-minute SLA.
NO [Standard]: Enqueue into standard regional redistribution pool for scheduled pickup clustering.
P = 0.3·S_qty + 0.5·S_fresh + 0.2·S_time
DECISION D5 • NGO MATCHING
Primary NGO Accepts within Response SLA (15m)?
YES [Accepted]: Lock reservation; update status to ACCEPTED; assign capable volunteer transport agent.
NO [SLA Timeout]: Auto-escalate reservation lock; pop next ranked NGO in spatial queue; cascade notification with urgency boost.
S_ngo = 0.4/Dist + 0.35·Cap + 0.25·Speed
DECISION D6 • CVRP CAPACITY
Cumulative Payload Exceeds Vehicle Limit (C_max)?
YES [Overflow]: Capacity Split Resolution: automatically insert intermediate depot dropoff before remaining pickups.
NO [Feasible]: Continuous multi-stop tour execution; saves 28.5% transit distance and transport CO2e emissions.
Current_Load + M_batch ≤ C_max
DECISION D7 • ZERO-TRUST GATE
Scanned Token Matches Database (τ_scan == τ_stored)?
YES [Verified Handshake]: Transition to DELIVERED; trigger closed-loop MAPE recalibration and commit SHA-256 ledger digest.
NO [Tamper / Fraud]: Zero-Trust Security Freeze: reject handover; lock volunteer session; flag audit incident to platform admin.
